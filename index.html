Toddler Kindergarten

This project contains a PHP + MySQL school management system. GitHub Pages can only serve static files, so this page is a landing page for the repository instead of running the app itself.

The full application requires a local PHP server and a database connection. To run it locally:

  • Open the repo in a PHP-enabled environment
  • Run: php -S localhost:8000
  • Visit: http://localhost:8000
  • For the admin dashboard, use the app pages from the project itself
